"Hello everyone! Today, I’m excited to present **TaskFlow** — a premium, SaaS-ready task management platform built for modern teams. ## Scene 2: Tech Stack (0:30 - 1:00)
**Visual**: Split screen showing code snippets (NestJS on left, React on right).
**Script**:
"Under the hood, TaskFlow uses a senior-level tech stack. The backend is built with **NestJS**, following a strict modular architecture for scalability. We’re using **MongoDB** for flexible data modeling and **JWT** with Access and Refresh tokens for secure authentication. On the frontend, we’re utilizing **React 19** with **Vite**, powered by a custom design system built on **Tailwind CSS v4** and the **Poppins** font for that elegant, premium feel."

## Scene 3: The Dashboard & Analytics (1:00 - 1:45)
**Visual**: Screen recording of navigating the Dashboard. Hovering over charts.
**Script**:
"Let’s look at the Dashboard. This isn't just a static page. We’ve integrated **Recharts** to give teams real-time insights into their productivity. You can see task distribution by status, priority breakdown, and an overall completion rate. To the right, we have a live **Activity Feed**, which acts as an audit log, showing exactly who did what and when across all projects."

## Scene 4: Projects & Kanban (1:45 - 2:30)
**Visual**: Navigating to Projects, then clicking into a project to show the Kanban board. Perform a drag-and-drop.
**Script**:
"The heart of TaskFlow is the **Kanban Board**. Using **@dnd-kit**, we’ve implemented a seamless, high-performance drag-and-drop experience. Tasks are categorized into 'To Do', 'In Progress', and 'Done'. Notice the attention to detail: overdue tasks are flagged with red alerts, and priorities are clearly badged. As an Admin, I can manage the entire team, while Members have a focused view of their assigned work, enforced by our backend **RBAC guards**."
